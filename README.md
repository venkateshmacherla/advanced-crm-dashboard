# Advanced CRM Dashboard

A modern Customer Relationship Management (CRM) Dashboard built with Next.js, TypeScript, Tailwind CSS, and TanStack Query. This project helps manage customer information with features like search, filters, pagination, CRUD operations, export, and dashboard analytics.

## Features

### Dashboard

- Dashboard overview with customer statistics
- Recently contacted customers
- Responsive dashboard layout
- Dark mode support

### Customer Management

- View customer list
- Add new customer
- Edit customer details
- Delete customer
- Customer detail drawer
- Duplicate email validation
- Duplicate phone validation

### Search & Filters

- Debounced search
- Filter customers by status
- Advanced filter panel
- Saved filter support
- Clear filters

### Table Features

- Sorting
- Pagination
- Bulk selection
- Export customer data to CSV

### Form Validation

- React Hook Form
- Zod validation
- Email validation
- Phone validation
- Required field validation
- Success and error toast notifications

### Data Handling

- TanStack Query
- Mock API
- Local Storage persistence
- Optimized data fetching

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to the project folder

```bash
cd advanced-crm-dashboard
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## Build

```bash
npm run build
```

---

## Run Production

```bash
npm start
```
